# 社会与种族

江国社会相对安逸，多种族共同生活，形成了较为复杂的共存体系。各族日常相处总体融洽，但仍存在小规模的歧视、偏见与不理解。

狼族普遍喜欢抱团，这一倾向同样体现在江国社会中。

# 网络与产品使用

[[江坝]]封锁了[[ID.STAFF-0|赫提]]服务，江国境内用户无法直接访问。

[[龙珀控股有限公司|龙珀]]的义肢价格高昂，目前尚未在江国开通售卖。包括富裕群体在内，江国的龙珀义肢使用者也较少。
