# 社会与种族

江国社会相对安逸，多种族共同生活，形成了较为复杂的共存体系。各族日常相处总体融洽，但仍存在小规模的歧视、偏见与不理解。

狼族普遍喜欢抱团，这一倾向同样体现在江国社会中。

# 家族与人物

## 苍家

[[No.3-3-54-2|苍斌]]与[[No.2-2-53-5|苍檩]]出身于江国苍家，是入职前便有血缘关系的亲兄弟：苍斌为哥哥，苍檩为弟弟。

- **苍斌**：No.3-3-54-2，绿狼，入职前为柔道教练，曾在[[长洲大学]]柔道部任教。
- **苍檩**：No.2-2-53-5，黄狼，射击俱乐部常客。就读长洲大学期间，与[[No.2-0-60-2|临熙]]同住一间宿舍；这段室友经历发生在两人入职前。

苍家的具体居住地尚未明确，不以两人的在校经历推定家族住址。

# 网络与产品使用

[[江坝]]封锁了[[ID.STAFF-0|赫提]]服务，江国境内用户无法直接访问。

[[龙珀控股有限公司|龙珀]]的义肢价格高昂，目前尚未在江国开通售卖。包括富裕群体在内，江国的龙珀义肢使用者也较少。
