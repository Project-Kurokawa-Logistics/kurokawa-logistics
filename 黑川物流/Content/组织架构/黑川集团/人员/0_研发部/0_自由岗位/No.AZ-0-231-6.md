# 报告

该个体出身于南方某城的武馆家庭，自幼习武，少年时期曾获得多项奖项。患有先天基因病，长有鱼尾，早期肌肉与骨骼强度一度超过常规赤狐兽人。随年龄增长，逐渐出现肢体失衡、脏器病变与呼吸困难，被迫停止习武。

家人为其治疗变卖武馆等财产，仍负债累累。该个体长期自责，曾服药自杀，被家人及时发现救回。此后离家打零工，持续寻找治疗与偿债的机会。经已入职我司的医生介绍，得知我司可能提供治疗，遂提交申请，希望以工作换取生存及为家人还债的机会。

其特殊身体引起了 [[No.AZ]] 的关注。入职后留在研发部自由岗位接受治疗与观察，并配合藏品优化科进行身体平衡及动作适配测试。
