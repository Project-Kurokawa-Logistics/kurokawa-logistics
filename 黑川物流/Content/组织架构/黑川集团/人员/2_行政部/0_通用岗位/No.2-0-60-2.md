# 临熙

| 编号   | No.2-0-60-2 |
| ---- | ----------- |
| 名称   | 临熙          |
| 代号   | 偃光          |
| 原种族  | 粉纹黑虎        |
| 入职年龄 | 23 岁        |

出身于远东地区，幼年时因家庭卷入黑帮冲突沦为孤儿，后进入[[牙暗组]]成为家族继承人贴身侍卫并接受训练。喜欢棒球、柔道与剑道，识风水并略微迷信。

“[[钩沉决滞 设定汇总#《钩沉决滞》时间轴|御家骚动]]”后追随帮派二把手[[No.3-3-54-2-B|熠椴]]脱离牙暗组，一同逃往江国并以留学生的身份就读于[[长洲大学]]，毕业后留在校内继续参与校棒球队活动。

日常温和细腻，对喜欢的事物有着高顺从度与依赖，在其受到任何伤害或玷污时会变得残暴冷血并极具攻击性。黑胶匹配度与自我精神保持能力都很高。
