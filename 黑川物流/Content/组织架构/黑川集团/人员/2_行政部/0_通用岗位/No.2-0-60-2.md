# 临熙（“偃光”）

| 编号   | No.2-0-60-2 |
| ---- | ----------- |
| 名称   | 临熙          |
| 姓氏   | 临           |
| 名    | 熙           |
| 代号   | 偃光          |
| 原种族  | 粉纹黑虎        |
| 入职年龄 | 23 岁        |

出身于[[秋津国]]远东地区的黑原家，原名**黑原熙临**（姓黑原，名熙临）。幼年时，黑原家与紫椴家因盟约往来密切，他从黑原家被选送至紫椴家，改姓“紫椴”，称**紫椴熙临**，作为家族继承人的贴身侍卫接受训练，与紫椴熠一同长大。喜欢棒球、柔道与剑道，识风水并略微迷信。

“[[钩沉决滞#5|御家骚动]]”时，为追随青梅竹马[[No.3-3-54-2-B|紫椴熠]]而脱离黑原家，并在紫椴焱的帮助下护送紫椴熠离开秋津，一同逃往江国。

赴江国后，为保密改用姓名**临熙**，姓**临**、名**熙**，以留学生的身份就读于[[长洲大学]]，与苍檩同住一间宿舍；毕业后留在校内继续参与校棒球队活动。

日常温和细腻，对喜欢的事物有着高顺从度与依赖，在其受到任何伤害或玷污时会变得残暴冷血并极具攻击性。黑胶匹配度与自我精神保持能力都很高。

## 人际关系

- 该个体极度效忠并暗恋[[No.3-3-54-2-B|354B]]（江国档案姓名椴熠，私下昵称熠椴），两人自幼相伴。
- 与[[No.2-2-53-5|253]]（苍檩）同为法学专业的同学、好友，入职前曾是同寝室室友。
- 反感并敌对[[No.3-3-54-2|354]]（苍斌）；苍斌是其好友苍檩的亲哥哥。
