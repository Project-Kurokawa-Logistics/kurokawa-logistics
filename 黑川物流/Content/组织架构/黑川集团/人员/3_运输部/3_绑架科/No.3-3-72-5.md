# 桑砚

| 编号   | No.3-3-72-5 |
| ---- | ----------- |
| 名称   | 桑砚          |
| 原种族  | 鲸尾黑龙        |
| 入职年龄 | 24 岁        |

# 报告

该个体入职前曾从事快递配送。为筹措治疗费用，曾在俱乐部工作，所得不足以支付开销，遂向黑川集团借款并接受注射，由此与集团建立联系。

后遭一名地产商扣留，期间得知原配送站点已被拆除。该个体在应激状态下一度突破[[限制锚]]，接入胶兽网络并调用[[No.3-3-33-0|艾迪]]的战斗数据，随后失去对黑胶的控制，由公关部回收。

该个体熟悉配送业务，入职时主动提出进入运输部绑架科，遂编入该科。

# 批注

权限评定为 **5 级**。回收前的异常表现发生于应激状态，且涉及调用外部战斗数据，不作为其常态黑胶操控能力的评定依据。
