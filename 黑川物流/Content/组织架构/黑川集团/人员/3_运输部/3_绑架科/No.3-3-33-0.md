# 报告

艾尔德里奇 (Eldritch)，原姓氏不详，黑胶科技泄露灾害二级受害者（接触了黑胶科技的产物）。

以下为我司根据其记忆数据和背景调查还原出的事故报告：

在涉及 [[No.7-4-47-0]]（格拉菲特，即“石油雨”）的实验室中，一种由含有远古虫人数据情报的黑色胶原矿制成的非法药品，在实验室因为无法产出结果的情况下，由内部人员非法流出至他国。此产品具有初步同化犬科（尤其是狼兽人）肉体的能力，并且会随消化系统留置全身，在极小概率下会将其蕴含的情报填补至大脑。该个体患有部分伴丘疹性损害无毛症，身体区域多块斑秃，其家庭为其寻来了此非法药物并喂下的同时，给予了巨大的精神压力，导致黑胶同化并填补了该个体损伤的皮肤部位和部分神经元。

根据数据分析，我司在该个体的大脑内发现了通过黑胶同化注入的已灭绝的虫人基因。该个体在其亲身父亲自杀后，由于机缘巧合的原因，将黑胶生物的捕食本能转化为了对雄性生殖器官及其分泌物的渴求本能，其本能与我司限制锚科技导致的渴精症无关，而是一种繁殖欲和虫族的同类相食基因混合导致的社会产物。在切割并吞下自己的生殖器后，该个体因自我吞食加重了黑胶同化程度，在肉体得到强化的情况下开始连环杀人做案，并吞下雄性的生殖器来满足其欲望。

该个体之所以会被我司发现，是因为一名运输部出差藏品在执勤过程中被其杀害。该遇害藏品及时地进入了冬眠状态并发出求救信号，在损失了部分神经和肉体的情况下，通过快速固化的黑胶拖住了该个体。执勤遇害藏品的肉体已破损严重无法修复，目前已压缩全身肉体转化为胶兽核心。

在成功捕获该个体后，我司迅速地意识到了这是一起黑胶科技泄露灾害的受害者。其体内的狂暴无序黑胶的同化程度已经即将达到致死的浓度，只能进行胶兽进化处理。由于部门内部存在多方争议，该个体最终被剥去用于行动的胶液单元，只允许以数据精神体的形式保持清醒。在经过数月的精神治疗中，该藏品以积极向上的态度成功融入我司工作中，以训练对象的身份等待被全公司的藏品使用。

罪机“E.D.D.Y.”在各种交通工具的驾驶和行踪隐藏方面具有丰富的经验和本能天赋，对于需要经常执行绑架回收任务的运输部藏品来说，具有重要的学习意义。该个体的技能数据已整理上传，无偿对所有运输部和工程部的藏品开放。

# 批注

在该次意外事故中，我司总结了以下几个问题：

1. 在本次事故后，我司意识到了黑胶科技泄露事故的严重性，今后人事部将会增加出差人员，以搜寻散落在世界各地的黑胶矿产和科技萌芽。
2. 我司成员对于实战和对于黑胶生物的内战方面存在严重的经验不足，罪机“E.D.D.Y.”已被制成战斗训练用藏品，将添加至所有出国出差的藏品的训练项目中。
3. 我司对于精神扭曲的人类个体能够起到很好的治愈作用，但是未被标准化，人类人格较为充裕的个体与其精神交流时仍有可能出现意外。今后将会使用胶奴执行体对精神扭曲的个体进行精神治疗，必要时可切割部分记忆神经压缩成液晶射出。
