# 报告

江国档案姓名为**椴熠**，私下昵称**熠椴**，原名**紫椴熠**（姓紫椴，名熠）。出身于[[秋津国]]远东地区的紫椴家，是[[紫椴玄岳]]的次子、[[紫椴焱]]的弟弟。父亲与哥哥均为[[鬼族|鬼虎族]]；父亲的具体外观尚未明确，哥哥为白毛鬼虎，现任[[紫椴通运]]负责人及[[牙暗组]]组长。

紫椴家早年经营危险品走私。该个体原考取[[秋津国#浦都|浦都]]一所大学的国际物流管理专业。因与家族理念不合，他在“[[钩沉决滞#5|御家骚动]]”时得到哥哥紫椴焱的帮助，由自幼相伴的粉纹黑虎[[No.2-0-60-2|紫椴熙临]]护送前往[[纵横江多种族人民共和国|江国]]，后在[[长洲大学]]学习物流管理。

紫椴熙临原名**黑原熙临**，幼年时因两家盟约被选送至紫椴家后改姓“紫椴”，在骚动时为追随该个体而脱离黑原家。赴江国后，为保密改用姓名**临熙**，姓**临**、名**熙**。

人事部在调查 [[No.3-3-54-2|354]] 号（苍斌）的背景前就发现了该个体，出于对本国社会秩序的保护，该个体被多次列入清缴奴化清单中，但由于其周边始终存在未查明的隐藏监护人员，且远东区域的后续处理缺乏人手，因此暂时搁置了绑架计划。

在 354 号被转化后，354 注意到该个体与其家族理念存在分歧，具有利用的价值。然而在 354 调查的过程中，其狩猎本能失控，提前将目标熠椴在柔道部更衣室内将目标转化为了其子代。[^1]

大量的胶原注入和不正常的洗脑步骤使其惨堕为胶奴，在经过抢救后才成功维持住人格。

经过一段时间的观察，确定其人格稳定下来后，我司决定继续让其在校进修，同时着手处理其远东区域的本家。

# 批注

“藏品对其长时间接触的熟人人类有更强烈的捕食和繁育欲望，人事部需加强对入职目标的人际关系的记录，以避免更多此类事件的发生。”
