# 报告

出身于[[纵横江多种族人民共和国|江国]]苍家，是[[No.2-2-53-5|苍檩]]的亲哥哥，兄弟关系在入职前便已存在。入职前为柔道教练。

该个体由于长期过量训练柔道而使得身上留下了很多隐疾，在一场柔道比赛里旧伤集中复发后被迫退役，并回到[[长洲大学]]担任校柔道部助教、教授柔道。

弟弟[[No.2-2-53-5|苍檩]]入职后立即向人事部提交了该个体的信息，并在下班回家后积极游说哥哥入职，但并未取得明显进展。

No.3 从人事部得知了解此事后立即亲自前往该个体所在的柔道俱乐部，并在该个体即将下班时于更衣室进行捕获。No.3 在与其激烈缠斗了几回合后才终于成功地将其制服，在植入了锚后将其打包并直接送回总部。

入职后，被胶液修复了身体的苍斌充分发挥着自己的格斗经验与才能，很快成为了 No.3 的得力下属，他一边努力适应被胶液同化后所带来的全新工作与生活方式，一边在执行任务的同时不断尝试将柔道技巧融入到绑架手法中，取得了不错的成果。

据了解，该藏品在阅读了运输部内部著作《翻花绳》之后，也正在筹备发表属于自己的著作。

虽然行政部与运输部之间关系略显紧张，但该藏品在空闲时经常前往行政部找弟弟[[No.2-2-53-5|苍檩]]玩，后者也常常与苍斌一同出没于员工咖啡厅与食堂。
