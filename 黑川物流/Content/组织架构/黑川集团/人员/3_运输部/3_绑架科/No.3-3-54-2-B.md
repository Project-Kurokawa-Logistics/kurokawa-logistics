# 报告

江国档案姓名为**椴熠**，私下昵称**熠椴**，原名**紫椴熠**（姓紫椴，名熠）。出身于[[秋津国]]远东地区的紫椴家，是紫椴玄岳的次子、紫椴焱的弟弟。父亲与哥哥均为鬼虎族；父亲的具体外观尚未明确，哥哥为白毛鬼虎，现任[[紫椴通运]]负责人及[[牙暗组]]组长。

紫椴家以危险品走私起家。该个体与家族理念存在分歧，在“御家骚动”时得到哥哥紫椴焱的帮助，由自幼相伴的粉纹黑虎黑原熙临护送离开秋津，赴[[纵横江多种族人民共和国|江国]]就读[[长洲大学]]，学习物流管理。

黑原熙临幼年时因两家盟约被选送至紫椴家，在骚动时为追随该个体而脱离黑原家。熠椴后来赐其“紫椴”姓氏，完整姓名为**紫椴临熙**；出于保密，通常仅称[[No.2-0-60-2|临熙]]。

人事部在调查 [[No.3-3-54-2|354]] 号（苍斌）的背景前就发现了该个体，出于对本国社会秩序的保护，该个体被多次列入清缴奴化清单中，但由于其周边始终存在未查明的隐藏监护人员，且远东区域的后续处理缺乏人手，因此暂时搁置了绑架计划。

在 354 号被转化后，354 注意到该个体与其家族理念存在分歧，具有利用的价值。然而在 354 调查的过程中，其狩猎本能失控，提前将目标熠椴在柔道部更衣室内将目标转化为了其子代。[^1]

大量的胶原注入和不正常的洗脑步骤使其惨堕为胶奴，在经过抢救后才成功维持住人格。

经过一段时间的观察，确定其人格稳定下来后，我司决定继续让其在校进修，同时着手处理其远东区域的本家。
