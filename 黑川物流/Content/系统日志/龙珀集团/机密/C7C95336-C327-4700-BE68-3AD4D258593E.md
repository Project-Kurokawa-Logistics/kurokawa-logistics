# ROOT 办公室内的对话记录

> 墨狡正式提出入职申请的前一日下午，ROOT 办公室内

“老板，您找我。”

“这个人是你推荐来的，说说你对他的了解吧。”

“我第一次认识他是在他大二的时候，武道社社团的迎新会上。由于大二才加入社团的学生不多，而他又在新人的成绩中很亮眼，所以作为在社团混了几年的老石头，我就和这个新人认识了。从初识到入职龙珀之前，我一直没彻底击败过他，甚至只在他状态不好的时候才能和他打到有来有回。嗯……再就是这家伙不论什么时候参加比赛，他都把自己的名次控制在第七名上下，还因此招致很多对手的不满。不过他貌似完全不在乎别人的不满，也不在乎外面谣传的吹嘘与诋毁，所以向来没人知道他的真正实力。直到入职龙珀之后，通过前几天的测试，我才将他的实力彻底量化出来。”

石铠从身后拿出一份自己研究的数据，交给了 ROOT。

“这是我平时研究的东西，虽说我对电能方面不甚了解，但以我对他的预测，在龙珀的科研能力上得出的数据，只要他有兴趣，我相信他是一定会对研究非常投入，并且也能做好开发者级别的研发工作的。不过对于格斗方面，目前不做机械改造的他确实无法赢下我，只是我如果想要彻底打赢他的话也得费上一番功夫。”

石铠抬起头，ROOT 的眼神正告诉石铠他已经知道了石铠的想法。石铠避开了那道凌厉的眼神，继续说了下去。

“由于关系到我的研究方向，这些数据的处理已经有一定的难度了。如果他可以完成这次测试的话，我希望墨狡可以以非高机械程度的完整人类方式进入开发者组别参与龙珀的研发工作。”

“龙珀重视人才，不会阻止任何一颗明星绽放他的光。”ROOT 掏出随身的钢笔，在纸面上更改了部分数据之后，递给了石铠，“你为什么觉得他会入职龙珀？”

石铠看着那些被钢笔修改的数据，只有那些最基础的给定数据被修改为与现实相去甚远的数字和公式。他不懂老板在做什么，而自己本来也无法处理这些数据，所以只得按 ROOT 想的做。

“老板，我已经在他不知情的情况下给他植入了龙髓并且控制他了，您应该收到过我曾提交的墨狡的龙髓植入申请。”

“控制？”ROOT 看着石铠，皱了下眉头，略带疑惑地看着他。

感到有些不舒服的石铠点了点头：“对，控制了他。老板，我不是生科专业吗，之前研究的课题中涉及到了催眠这一点。墨狡说他最近睡眠不好，我就趁机在潜意识中给他植入了一些龙珀相关的积极意识，再加上平时公司的待遇、宣传和如今的毕业季，这么好的机会他几乎是不可能放过的。”

石铠见 ROOT 的眉头松了下去，心头的异样也随之消散。

“你怎么敢保证他不会在意识到你的催眠后，报复你，也报复公司呢？”

“他本意就是想进入龙珀工作的。我也是为了他和公司着想，所以他没有比入职更好的选择了。如果他执意不想入职的话…我会了结他。”

ROOT 瞥了一眼石铠攥在一起的双手，淡淡地看着石铠的眼睛：

“好，我默认你心里的想法不会影响到公司。既然你已为他担保，那明天就把他带到这间办公室来。”

“啊？老板您要亲自面试吗？”石铠的声音顺着转过椅子去的 ROOT 升了个调。

“如果你现在改变了想法，提前做掉他还来得及。”

ROOT 挥了挥手，示意石铠离开。石铠知道，自己早已经改变了他的人生，而现在能做的，就是希望不要由自己亲手杀掉他。
