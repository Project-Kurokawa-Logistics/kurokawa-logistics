# 限制锚与龙髓的职责对照

> 更新日期：2026-10-20。替换旧版自动生成的对比稿。龙髓按本轮“信号中间人”口径整理；限制锚的新定义先记录于此，正式概念条目及剧情的修补仍须另行审阅。

## 一、龙髓：信号中间人

龙髓连接人体神经信号与设备指令，负责在两者之间解析、翻译与写回反馈。

- **下行**：取得运动意图等信号，转成义肢或已配对设备可以执行的指令。
- **上行**：接收设备反馈，转成大脑可理解的信号，模拟触感。
- **义肢链路**：液压传感义肢 → 龙鳞 → 龙髓 → 大脑。义肢连接处的皮肤及神经需要龙鳞打底。
- **控制与塑造**：信号拦截、动作控制、感官反馈及长期行为引导，可以逐渐塑造习惯、倾向和条件反射；不自动等于写入某种思想。

龙髓是龙珀精密设计和制造的成品芯片，不是生物芯片，不会生长。它安装于脑干，后续维护不便，但植入时的成品本身已足够完善，不依靠持续养护来成熟或完成功能。旧稿“只在脖颈、绝不进入脑内”的定义不再使用；具体术式按新设定另行修订。

### 基础功能的边界

- 不直接读取具体思想。
- 不直接整理、改写、删除或植入记忆。
- 不生成第二人格，不把教条作为宿主本人的念头写入。
- 配对设备可以按固定指令操作；龙珀安保定制的门禁、保险柜等设备容易完成配对，不意味着通用破解任意设备。

### 赫提的推测不等于直接读心

龙髓取得身体与脑部的传感数据，并与赫提通信。赫提可据这些数据推测行为和叛变倾向；这是分析与判断，不是读取具体念头。误差、阈值与具体实现不在本稿补定。

**赫提网络不参与触感生成。**本地触感回传与传感数据分析是不同职责。旧版“只接收外部命令、绝不向外传输”的全面禁令不再采用。

### 内部实验扩展：“龙髓 DLC”

记忆管理、忠诚内容与自我叙事修改，归入龙珀内部研究的额外模块，暂以“龙髓 DLC”称呼；不是标准龙髓自带功能。

这类研究并不稳定，也没有黑川限制锚的成熟度。石铠、昱江及 ADMIN 相关表述仍需专门审阅，本稿不替具体档案补定安装史或效果。

## 二、限制锚：调和人类思维与胶兽思维

以下是本轮主创明确的新口径，**先作为待修补依据，不在本次对照中改写正式档案或正在编辑的《漆黑的新羽》第二章**。

- 胶化身体会产生胶兽思维，与原有人类思维形成需要调和的关系。
- 限制锚是调和这两者的处理器，最终两个人格会合二为一。
- 胶有扩张、摄取血肉及让他人变成胶兽的倾向。限制锚限制胶兽能力与繁殖欲望，并将部分倾向转化为“渴精症”等其他表现；还有其他功能，待逐项整理。
- 黑川不希望收编者变成完全由胶液构成的纯胶兽，也不希望其完全失去自我。
- 限制锚并不意味着从此完全停止身体胶化；对进程、能力与人格的限制，需要与相关档案一起修补。

旧稿将限制锚简单概括为“直接抹去原有人格、彻底忘我”，或断言使用者始终毫无抗争感，均不再采用。

## 四、已丢弃的旧稿推论

- 从“传感反馈”直接推导为检测某个具体反抗念头。
- 以大脑算力劫持为理由，断定龙髓能后台生成第二人格。
- 把梦境、内分泌或奖惩机制的具体细节写成已经确定的通用技术。
- 将两家公司的所有宿主体验固定为同一种模式。

仍可继续使用的只有职责层面的区分：龙髓主要在信号通路上发挥作用；限制锚涉及胶化后的人格调和与能力限制。具体人物怎样受影响，应由档案和剧情分别说明。
