## 一、黑胶的功能分化

[[原初黑胶]]的不同部分能够特化为不同功能。同源的黑胶可以有不同的能力侧重，外观与世代相近也不代表功能完全相同。

| 个体                   | 功能侧重     |
| -------------------- | -------- |
| [[No.AZ      \| AZ]] | 分裂、增殖与同化 |
| [[ID.STAFF-0 \| 赫提]] | 思考与情报处理  |

**功能特化体现的是能力侧重。**某部分更擅长一种功能，不代表它的其他能力必然完全消失。

## 二、龙鳞的同化与增殖

[[龙鳞]]源自赫提，**同化能力很弱**，但仍能使覆盖部位的皮肤与神经发生局部胶化。在龙髓配合下，这些胶化部位可以成为肉体与机械设备之间的接口。

**龙鳞具有局部同化能力。**局部皮肤神经胶化与整个人成为纯胶兽，是不同的状态；具体接驳和信号通路见[[龙髓、龙鳞与义肢]]。

龙鳞可以繁殖、增殖与同化，但需要满足苛刻条件，具体条件尚未设定。其资源瓶颈按这一方向解释，已不采用“材料用一点少一点、永久无法再生”的设定。这一约束不直接推广为所有原初黑胶的统一规则。

胶材料的供应规模与大众赫提的装机量分别讨论；软件安装数量与可用胶材料之间的对应关系，目前没有定案。

## 三、兽人的起源

兽人的起源发生在尚未形成成熟文明的远古时期，其演化过程为：

1. 远古的人形灵长类生物受到黑胶影响，成为母体。
2. 母体摄食其他动物，通过黑胶的解析与同化，使动物信息参与融合与演化。
3. 这一过程逐渐产生不同的兽人种族；后代的黑胶同化程度较低，相关成分随世代繁衍而稀薄。

**现代兽人是黑胶参与生物演化的结果。**主线时代的“人类”通常指这些兽人；远古人形生物与当代称谓的区别见[[兽人（人类）]]。

不同兽人种族长期交战，曾阻碍文明发展，并造成严重的历史断层；现代社会是在此基础上逐渐稳定下来的。

## 四、血脉与返祖

现代兽人体内都留有微量黑胶胶质，这是共同演化来源的延续。少数血脉浓度偏高的个体会表现出“返祖症”，出现更接近纯兽的身体特征，例如 AZ 的牙齿，以及某些个体的弓足、马蹄或肩背结构。

**返祖现象已经纳入设定，但具体特征的来源仍须分别判断。**其他个体的长角来源仍须分别核定，不能统一归为返祖或鬼族血统；鬼族相关说明见[[鬼族]]。
