# 报告

白夜星川，代号 Dainese，具有江国与秋津国血统的狼族雄性，现于江国当地的笑川殡葬任入殓师。其家庭经济宽裕，选择殡葬行业的动机主要来自母亲的工作经历：母亲曾负责公共交通事故处理，他从中听闻了许多不幸的遭遇，希望通过自己的工作，为这些逝者做最后一件事。

根据其提交的履历，该个体出生于[[纵横江多种族人民共和国|江国]]某沿海城市，母亲为[[秋津国]]人，父亲为江国人，姓名采用秋津语。四岁时，他随父母移居卡玛特共和国北方[[特拉海]]上的岛国[[库普雷斯共和国|库普雷斯]]。母亲在当地公共交通公司担任事故处理专员，父亲则在地质局担任地质研究师。

成年后，该个体以较好的成绩考入当地的[[莱夫科萨大学]]，修读殡葬专业。毕业约一年后，库普雷斯发生内战，国家分裂，位于中央的首都莱夫科萨也被缓冲区与边境墙分隔，母亲随后失业。随着治安恶化与帮派势力扩张，他加入了当地帮派，并有过较长时间的街头生活。原履历提及其曾在首都边境墙一带参与毒品走私，并有蓄意伤害等不良记录；据其自述，这些记录后来因父亲的关系被消除。

在当地局势持续紧张后，全家决定利用多年积蓄进行长期旅行，首站前往[[诺德维格王国]]位于北极地区的[[萨巴德群岛]]与[[羊马延岛]]。父亲对萨巴德古老而复杂的岩层，以及羊马延的火山地貌颇感兴趣。此后，一家人又陆续前往[[普罗德合众国|普罗德]]等国家，最后返回江国定居。依本人意愿，白夜星川住进祖父母家中，父母则居住在同城东部的新建住宅区。其家庭成员包括父母、祖父母及外祖父母。

回国初期，该个体并未立即就业。一次在便利店吃宵夜时，他结识了一名刚结束“跑山”的[[No.1-5-23-2|鳄鱼兽人]]。在交谈中，他对机车及对方身上的专业装备表现出强烈兴趣，随后受邀加入当地机车俱乐部。此后的两年里，机车活动与俱乐部社交占据了其生活的大部分时间；再之后，他进入笑川殡葬，开始从事入殓师工作。
