# 3

三月的浦都，海风湿冷，雨水裹着细碎的冰粒从港口方向灌进来。

北阜区的旧市政广场上，雨伞黑压压地挤成一片，各种人声混成一团。广场中央临时搭起的白色祭坛上摆了些白色菊花，祭坛两侧悬挂着黑色的挽联，上面印着“浦都暴乱四周年遇难者追悼仪式”的字样。几名制服警察懒散地站在广场四角，两两挤在一把伞下玩手机。

一个身影站在人群最后方，与祭坛隔着将近五十米的距离。

那是一个白虎青年，他穿着一身墨色西装，暗红色短袖衬衫的领口处别着一枚极小的白色梨花形胸针。他橙红色的瞳孔像哑光的琥珀，一对白底黑边的虎耳从黑色短发两侧竖起，三条橙红色的虎纹如同凝固的血渍般横在他两侧的脸颊上。带着橙黑相间条纹的虎尾垂在身后，尾尖嵌着“装饰用”琥珀色玻璃。一对与种族并不相称的黑色鬼角对称地竖在白虎青年的额头上，了解历史的==远东人==都清楚，这是早已==灭绝的纯血鬼族最具辨识度的特征。==

鬼族是远东地区的土著陆生种族，在史书中以凶恶、好战与淫靡著称。从地方叛乱到入室强暴，都有这支种族的身影，远东文化中也因此诞生了许多“驱鬼”元素，即便后世研究表明，部分史料有所夸张。由于低生育率和远东地区古代的数起战争，到现代，纯种鬼族早已灭绝，继承其微薄血脉的混血鬼族族群数量也屈指可数。

然而鬼虎并没打算隐藏身份，手中的伞是在路边便利店随便买的，透明塑料柄与他身上那件手工缝制的西装格格不入，伞面也遮不住他健硕的身躯。可白虎对雨水的侵袭丝毫不上心，任由尾巴与手臂被寒雨浸透。

祭坛前方是块巨大的长条形纪念碑，刻着“浦都暴乱遇难者慰灵碑”几个字。碑文下方用小字写着官方定论：境外势力煽动的分裂活动，造成三百二十一名无辜市民遇难。三百二十一名遇难者中，至少有十分之一是“==牙暗组==”的成员——白虎记得每一位遇难若众的名字。还有一个名字，属于他的父亲。

==白毛鬼虎名为紫椴焱，紫椴通运的领袖，也是远东地区最古老的黑道家族——“牙暗组”的组长。==

只有他一个人来，没带保镖，甚至连个接送的司机都没有。

骤然加大的雨势让献花的队伍变得稀稀拉拉。献在遇难者名字前的白菊花被豆大的雨滴打散，花瓣落在积水的石板上，随后被来来往往的人流碾成黑泥。慰灵仪式简短而官方，市政府的代表站在伞下念了一篇措辞小心的悼词，重点强调了维护社会稳定和打击境外势力渗透的决心，对遇难者家属表达了公式化的慰问。伞下有人抬起头，望向广场中心；更多人盯着手中那块泛光的手机屏幕，沉默着前进。紫椴焱的唇角牵动了一下，随即化作一声极轻的嗤笑。

在人群的推搡中来到石碑前，鬼虎找到那再熟悉不过的位置，从西装口袋里翻找出一个小花布袋，里面塞满了他亲手制作的梨花标本贴纸。他将贴纸一一取出，贴在那些名字旁。幼年时，紫椴焱每逢与若众御目见，都会赠送一片以示信任。现在的他依旧履行着这独属于自己的仪式，即便他们曾经存在过的证明只剩下几条冰冷的刻字。

直到目光停留在==紫椴玄岳==的名字上，鬼虎的身体凝滞了片刻，随后收回了手，转身离去。

他并不知道自己该怎么面对那个人。

雨下得更大了，斜斜地劈过来，豆大的雨珠打在那把可怜的小黑伞上，伞面被风刮得时不时翻个面。紫椴焱干脆收了伞，绑好，随后丢进路边难得一见的垃圾桶里。冰粒和雨水直接砸在他那对黑色长角上，顺着角根淌下来，浸湿了额前的短发，再沿着脸颊上那三道橙红色的虎纹滑进衬衫领口。

身后的慰灵碑前，人群依然黏腻地流动着，少有人注意到一个淋着雨的高大背影正离他们远去，就像没有人会在意多一个或少一个在雨中行走的黑色影子。

拐过广场西侧第一个巷口时，紫椴焱停住了脚步。

“出来。”

雨声几乎吞掉了他的声音，但巷子深处贴墙而立的影子还是动了，一个年轻的黑熊兽人从自动贩卖机后的隐蔽处走出来，身上黑色的小西服早已完全浸透。他站定后深深鞠了一躬，雨水顺着头发泼下来。

“组长，对不起。我……”

“谁派你来的。”

“是我自己……”==若众==的声音发着抖，“==若头==说过您出门不带人，我怕您……”

“怕我什么？”紫椴焱凝视着他，声音被雨幕压得低沉又混着些许戏谑，“怕我被人撒把豆子就弄死在街上？”

年轻的若众没敢接话，肩背绷得很紧，低头盯着路面，仍维持着鞠躬的姿势。紫椴焱的视线凝滞了两秒，随后将额头湿透的刘海往后捋了捋，雨水从指缝间流下来。

“回去。”

“组长，雨这么大——”

“我说了，回去。”他的语气并不重，甚至和缓，却又像这雨一样冷。

黑熊咬了咬牙，深深鞠了一躬，转身往另一条巷子跑去，脚步声很快被雨声吞没。

# 5

北阜区旧市政广场西侧是一片商业街。一到夜晚，大大小小的店铺招牌便亮起花花绿绿的霓虹灯，招揽来来往往的车辆与行人；远处绵延不断的金融天际线化作惨白的星河，点缀着阴云密布、下着反常冻雨的夜空。

父亲说过，几十年前此处还是广袤无垠的农田，其间散布着初具规模的远东式城堡。陆生种族们在这里与更内陆的群山中过着自给自足的生活，而海岸线与近海则是水生种族的地盘。短短两三代人的时间里，钢筋混凝土丛林从田野与海滨拔地而起，当权者脱下羽织换上西服，在田野与海滨劳作的人们纷纷走进店铺与写字楼，开始全新却又如出一辙的工作。原先被大小不一的渔船塞满的港口，现在停靠着数不清的远洋货轮。一切发生了翻天覆地的变化……当然是有代价的。

这么多年过去，远东桥附近的人流量从来没少过，无论清晨还是黄昏，也无论天气如何，只要信号灯一变绿，不同种族、不同年龄的人总会摩肩接踵地涌上斑马线，向街道的另一侧穿行而过。不同的是，如今秋津国的公民里头，绝大多数是熊、野猪、鹿、猫等陆生种族，水生种族…除了外地迁来的，基本已经绝了迹。

年纪长些的本地人都清楚，==秋津国是水生种族社群与陆生种族社群共同构成的国家==。远在上古时期，长期纷争不断的两大社群放下争端，合为一国。恶劣的居住环境与匮乏的资源，迫使少数水生种族成员靠出海抢劫邻国海滨村镇维持生计。直到几十年前，以[[普罗德合众国|普罗德]]为首的“国家联盟”牵头，联合远东的陆生种族，把矛头对准了所有水生种。“剿匪”，或者说——“屠戮”之后，大半水生种族成员流亡远洋深海，剩下的少数幸存者留在了远东，落入底层挣扎求生。陆生种族就此完全掌握了远东，再往后又赶上科技进步，现代化来得又快又彻底。

==这些事，紫椴家记得比谁都清楚，牙暗组从头到尾都掺在里头。我们是远东开国时便形成的陆生种族武士团，以维护本土陆生种族的利益为目标。在古代的领地合战中，我们负责提供武装力量；到了近代，我们就是那把最锋利、最血腥的“宰鱼刀”。“剿匪”结束后，武士身份成了历史，我们迫不得已转行整起了“特殊便”物流，随后在父亲的领导下创建了紫椴通运。至于黑帮，那群人爱怎么叫怎么叫吧，我干的事情确实不干净，可远东的历史也好，普罗德合众国的历史也罢，剥开了看又有几件是清白的？==

而牙暗组这名字底下，组长之位由紫椴家代代世袭，听说祖上一开始是纯血鬼族，但后来因战争、疫病与鬼族自身的某些“特性”，血脉越传越淡，到我这辈…就只是长有一双鬼角的虎了…呼…即便是天生耐寒的虎，也没法一直忍受这没完没了的冻雨，先在这街角的遮蔽处待一会儿好了。

父亲在世时，牙暗组还讲些老规矩，每年十月的某一天，紫椴家都会在这附近的一家老料理店包场，把若众们都叫来，从傍晚喝到深夜。父亲酒量很好，喝到最后还能用筷子敲着碗沿哼一段老歌，下面的若众们拍手大笑，声音能掀翻整栋楼。

谁也没有想到，这一切随着“御家骚动”如泡影般消散。
