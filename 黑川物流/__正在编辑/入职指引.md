# 参与企划能做什么？

1. 增加参与感。如果你只是想增加参与感，并只阅读黑川物流相关的作品的话，请跳到下方的【信息填写】。

2. 获得一个身份！获得一个企划世界观的身份后能做许多事情，你将能正式的参与到黑川物流周边故事的创作（当然要经过审核和校对），通过讨论设定来完善自己的故事，同时由人物设定的创造来完善故事中的地点设定。你的故事不仅仅是你的故事，群友之间的互动将能够带上你，让有你参与的故事变得更多！

3. 获得一些东西的抢先体验资格！群主和其他群友在创作的过程中，有时会出现仅企划人物参与/优惠的项目，黑川物流的主线故事和自助贴纸也会时不时采用企划角色的设定。

# 填写前需要注意的点！

*字不多，再坚持看一下！*

1. 我们推荐参与者重新转生！重新转生的意思是生成一个全新的设定，我们并不推荐任何擦边保有原设定的各种奇幻背景（如改造，被霸凌，实验室，异星生活，位面旅行者等等），我们鼓励参与者鼓起勇气去认真思考一个新的设定（当然，不是让你从零创建，外貌性格以及名字等可以沿用，只需要做相关兼容即可）。

2. 我们推荐在写设定时采用结果导向。我们注意到许多群友在入群前就已经拥有了自己的委托和自设，但是在做兼容和重新创造时又苦恼如何合理，我们推荐您将“设定目前的样子”设定成“故事中发生了一些事后变成这样”。例如小A拥有一件能够喷火的胶衣，那么我们推荐他将小A的设定定为“被黑川物流入职后，经过实验和数次测试做出了这套能喷火的胶衣”

3. 我们是现代都市软科幻！再强调一遍！

4. 不要有太大压力！我们在转化故事时会给你的设定添加大量在叙事上的留白，因此有不确定或者犹豫的地方不要有太大压力，后期补齐即可。这些留白是留给你用于填补系统日志又或者和群友联动用的，如果在一开始就定死的话，后期修改添加会非常麻烦。我么只提供一次免费创作企划身份的机会，后续想要由我们的写手帮你二次修改很麻烦的设定，又或者是大量入职新的设定的话，我们会收取一定的费用又或者将队列推后。

5. 我们提供直接登记！将基础的外貌写明白后，即可简短的快速入职，不过后续想要增加企划内的剧情互动的话，需要你主动努力和群友交流，来增加角色故事。

姓名：
你的名字。在世界观中，我们不严格限制名字格式，但是鼓励根据种族和地区有自己的命名规则。我们不推荐生僻字和英文姓名（但是可音译）。    

代号（选填）：    
如果你想彻底丢弃以前的名字，可以选择自取一个代号。在黑川物流和龙珀科技中，人在最终他们原本的名字会变成代号，真正的名字则是编号。

原种族： 
我们企划将兽人种族称之为人类，种族称之为兽种。请按照现实中设定的粗略分类填写并加上毛/皮色，例如：
苔原灰狼          小型红狼
黑发银灰犀     东方黑龙
东方混血狼龙
西方混血龙狼

其中，兽的要素占比比人类的样子要多的设定，请标明 返祖症
例如 返祖剑齿 东北森林虎

若是出现了  北美大型灰狼  北美棕熊 之类的地点说明，则只在设定中参考现实中动物的外表，无视地区前缀

入职年龄：
为了预防时间线混乱，我们只记录你的角色在参与黑川物流/龙珀科技相关时那一刻的年龄，用于固定大家对你的角色的印象。补充说明，我们不接受18岁以下的角色，即使是成年年龄提前的种族，也不宜提前过早。

加入方：
如果你是喜欢胶衣和扭曲情感的观众，推荐选择黑川物流
如果你是喜欢覆面覆甲和高科技装备，以及绝对服从的观众，推荐选择龙珀
请在黑川物流/龙珀后面附上部门，具体部门可在官网中的组织架构寻找。
**我们推荐通过阅读部门在日常中会发生的事情后再选择部门**


设定外貌：
简述外貌，若有设定图委托可放上来一张，为了减小文件体积，推荐进行裁剪而不是将一整张三视图放上来。

心路历程与核心（选填）：
**简述**人物在参与故事前的人生中，发生过的重大心理活动或者矛盾，并决定人物的核心
此条内容不参与我们对你人物卡的编辑，这个是用于后续创作故事时写情感用的。

核心：
