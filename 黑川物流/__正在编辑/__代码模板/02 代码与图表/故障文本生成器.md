# 故障文本生成器

[打开工具页面](./故障文本生成器.html)

用浏览器打开同目录的 `故障文本生成器.html` 即可使用，支持离线打开。如果 Obsidian 没有直接打开页面，可以在访达中双击这个 HTML 文件，或将它拖入浏览器。

## 使用

1. 粘贴想要转换的文字，工具会直接转换全部内容。
2. 调整故障强度和不透明度。默认为「强烈」和 **75% 不透明度**。
3. 查看实时预览，点击复制按钮。

- **复制 HTML · 含透明度**：粘贴到 Obsidian 的正文源码中，或在实时预览的编辑位置粘贴。阅读视图和发布页面会显示故障字，并保留设置的不透明度。
- **复制纯文本**：只包含故障字，可以用于普通文本，不带不透明度设置。
- **查看可复制结果**：可以手动选中复制；如果浏览器不允许自动复制，工具会展开并选中结果。

原有括号、标点、空格和换行都会保留，不识别或删除任何特殊标记。重复转换不会不断叠加故障符。
