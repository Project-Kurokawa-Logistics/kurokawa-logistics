本文件夹是库的写作与排版模板合集，按用途分了五个子文件夹。新手建议按下面的顺序上手。

# 新手阅读顺序

1. [[标题层级]] —— 井号分级，文档的骨架
2. [[换行与段落]] —— 严格换行下怎么分段、怎么紧凑换行
3. [[文字格式]] —— 颜色、居中、剧透隐藏
4. [[引号]] —— 弯引号 / 直引号 / 直角引号的使用规则
5. [[提示框]] —— Callout 提示框的全部类别
6. [[代码框]] —— 代码围栏、log 高亮约定

看完这六篇就能写出符合库内规范的页面了，其余按需查阅。

# 01 Markdown 基础

- [[标题层级]] —— 一到六级标题
- [[换行与段落]] —— 分段、行尾两空格紧凑换行、`<br>`、中西文间距
- [[文字格式]] —— 文字颜色、居中、黑底透明剧透条
- [[引号]] —— 中文弯引号、西文直引号、东亚直角引号
- [[提示框]] —— Callout 语法与全部类别一览
- [[特殊字符]] —— 黑方块、全角空格、进度条、分割线、注音标记、Nerd Font 字体

# 02 代码与图表

- [[代码框]] —— 代码围栏写法、log 语法高亮约定、Prism 支持的语言
- [[Mermaid]] —— 用文字画图：流程图、时序图、状态图、甘特图等
- [[合并 MarkDown]] —— 把多篇 md 合并成一个文件的脚本（macOS / Windows）
- [[故障文本生成器]] —— 输入文字生成故障字，调整强度与不透明度，并复制到正文

# 03 页面模板

- [[目录模板]] —— 目录页排版模板（横幅图 + 简介）

# 04 站点文件

- [[JS]] —— `publish.js` 的用途与注意事项（不要动）
- [[CSS]] —— `publish.css` 的用途与注意事项（不要动）

# 05 写作规范

- [[胶兽语]] —— KKN 伪终端报文格式、图标表、成帧规则
- [[龙珀]] —— ADMIN 组别忠诚话语的写法约定
