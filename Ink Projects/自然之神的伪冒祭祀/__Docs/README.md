# 《自然之神的伪冒祭祀》文档区

这里存放本 Ink 项目的设计记录、流程索引、变量索引、编写约定和待确认问题。**本目录中的 Markdown 是辅助文档，不会被主 Ink 文件自动载入。**

## 文档索引

- [故事流程与分支总览](STORY_FLOW.md)：按当前源码记录入口、主要章节、分支和结局。
- [Ink 编写约定](INK_CONVENTIONS.md)：区分项目中已经使用的写法与建议采用的维护规范。
- [变量与状态索引](VARIABLES.md)：记录已确认的核心变量、命名习惯和状态重置注意事项。
- [待确认问题与 TODO 清单](OPEN_ISSUES.md)：集中登记未完成选项、可疑跳转、角色连续性和需要试玩确认的逻辑。

## 记录原则

为避免把推测写成设定，文档使用以下标记：

- **源码事实**：可以在当前 .ink 文件中直接找到依据。
- **待验证**：静态阅读时发现疑点；需要编译、试玩或由作者确认。
- **建议**：推荐的后续维护方式，不代表现有源码已经遵循。
- **未完成**：源码明确含有 TODO、禁用标记或占位流程。

## 文档对应的源码范围

主要入口是 [自然之神的伪冒祭祀.ink](../自然之神的伪冒祭祀.ink)。它通过 INCLUDE 汇总 Characters/、Functions/、Maps/、Menus/、Misc/ 和 Pages/ 中的脚本。理解剧情时必须结合这些文件，不能只读入口文件。

## 维护规则

1. 新增、删除或重排重要剧情节点后，更新 STORY_FLOW.md。
2. 新增或改变状态变量、结局标记后，更新 VARIABLES.md。
3. 发现尚未实现的选项、可疑跳转或角色关系问题时，更新 OPEN_ISSUES.md；确认修复后记录解决方式，不要只删除历史背景。
4. INK_CONVENTIONS.md 中的“现有写法”应以源码为准；“建议”应明确标注，避免把规范提案误认为历史事实。
5. 修改分支后，至少检查入口、每个新选项的目标节点、返回路径和终止路径。若运行环境可用，应编译 Ink 并实际走通相关路线。
