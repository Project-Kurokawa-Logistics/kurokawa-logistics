# 回归测试清单

本清单用于后续修复或扩写时手动验证。勾选项不代表当前已经通过；执行测试时请补充日期、Ink 版本、宿主环境和实际结果。

## 1. 编译与链接检查

- [ ] 使用项目实际采用的 Ink 编译器编译主文件 [`圣诞大攻略：雷琥.ink`](../圣诞大攻略：雷琥.ink)。
- [ ] 确认所有 INCLUDE 文件都能找到。
- [ ] 确认所有 divert 目标存在，尤其是 `G_Dormitory`、`H_Tenement`、`Finale.F1`–`Finale.F11`、`TheEnd`、`Title` 与 `Misc`。
- [ ] 确认条件表达式没有类型错误或隐式类型转换问题。
- [ ] 确认 Ink 标签、图片、链接等指令能被当前宿主正确处理。

## 2. 主线入口

- [ ] 从标题菜单开始，确认 `CleanData` 会将 `Rate_LeiHu`、`Choose_YeHen`、`Choose_CenYe`、`Choose_LeiHu` 重置为 0。
- [ ] 在 Seg2 选择同意去宿舍，确认进入 `G_Dormitory`。
- [ ] 在 Seg2 婉拒后选择 Seg3 的两个选项，确认两条路径都按预期进入宿舍线。
- [ ] 在 Seg2 选择不去宿舍，确认进入 `H_Tenement`。
- [ ] 从 Seg2 的器材室分支进入 `B_Basement`，确认按设计到达 F11。
- [ ] 检查不同开场语气是否应当只影响文本，还是也应改变变量；目前开场选项未见显式数值变化。

## 3. 宿舍线数值边界

测试前记录三个倾向值与好感度。修复倾向判定后，至少覆盖：

- [ ] `Rate_LeiHu < 3` 且夜痕单独最高：应进入设计指定的路线。
- [ ] `Rate_LeiHu < 3` 且岑烨单独最高：应进入设计指定的路线。
- [ ] `Rate_LeiHu < 3` 且雷琥单独最高：应进入设计指定的路线。
- [ ] `Rate_LeiHu < 3` 且三个倾向全为 0：应进入已定义的默认路线。
- [ ] `Rate_LeiHu < 3` 且两人并列最高：应进入明确约定的平局路线。
- [ ] `Rate_LeiHu < 3` 且三人并列最高：应进入明确约定的平局路线。
- [ ] `Rate_LeiHu = 2`：确认仍进入低好感度判定。
- [ ] `Rate_LeiHu = 3`：确认进入 F8。
- [ ] 逐个选择宿舍线两组选择，核对人物倾向计数是否只增加一次、增加对象是否正确。

## 4. 出租屋线与好感度阈值

- [ ] 选择“拿起来嗅闻”，确认进入 F1。
- [ ] 选择“让他自己泄欲”，确认进入 F4。
- [ ] 选择“帮他泄欲”，将好感度控制在 0、1、2，确认按当前设计进入 F3。
- [ ] 选择“帮他泄欲”，将好感度控制在 3 或更高，确认按当前设计进入 F2。
- [ ] 分别测试 `Tune_On`、`Do_Nothing`、`Ask_LeiHu`，核对命名选项标签的条件文本是否只在对应路线显示。
- [ ] 核对“自己动手”与“叫外卖”路线是否在剧情、空调状态和选择菜单上保持一致。
- [ ] 测试 `{Tune_On or Ask_LeiHu}` 条件在三种空调选择下的显示结果。
- [ ] 核对每个会增加 `Rate_LeiHu` 的选择，避免阈值因重复加分或遗漏加分而变化。

## 5. F8、隐藏结局与多周目

- [ ] 未访问 F2 时进入 F8，确认 F9 选项不可见。
- [ ] 访问 F2 后重新开始一周目但不使用 RESTART，确认 F9 条件按设计解锁。
- [ ] 仅访问 F2、未访问 F7 时进入 F8，确认 F10 不可见。
- [ ] 访问 F2 与 F7 后重新进入 F8，确认 F10 解锁。
- [ ] 选择 F8 自身的“担心身体”结局，确认统计规则按产品定义处理。
- [ ] 选择 F9 或 F10，确认 F8 不会被错误地当作独立结局达成（若设计目标是区分“网关访问”与“结局达成”）。
- [ ] 从标题菜单返回、重新进入、关闭并恢复故事、点击 RESTART，分别检查访问记录是否符合设计。
- [ ] 通过结局回顾阅读已解锁结局，确认它是否应该计入“达成”数量。
- [ ] 通过“查看所有结局”阅读结局，确认开发查看行为是否应该影响正常结局统计。
- [ ] 检查 `FinaleCount`、`START` 与提示文案在 0、1、多个周目和全部结局时的显示。

## 6. 结局与 UI 文案

- [ ] 确认 F1–F11 的入口都能正常到达。
- [ ] 确认每个结局通过 `TheEnd` 返回后可再次进入标题菜单。
- [ ] 核对 `FinaleList` 与 `All_Finale` 的标题、编号、分类和实际结局一致。
- [ ] 确认新增结局时，结局总数与分类说明同步更新。
- [ ] 确认 F8/F9 的午餐来源叙事连续。
- [ ] 确认重复选项是否为刻意设计；若不是，检查修订后的选择是否有不同且可见的后果。
