最终自动回归在两套编译器输出上均为 **18/19 通过、1 项失败**：

```text
normal F2 then F7 unlocks F10 across retries without injecting variables
AssertionError: F7 must remain reachable through normal dormitory choices
```

45 条正常宿舍路径的结局分布为：

```text
F5 = 21
F6 = 6
F7 = 0
F8 = 18
```

旧实现中，部分正常路径是在三个比较条件都未命中后通过默认兜底进入 F7。改成“选择过即具备资格”并暂按候选顺序分流后，这些路径会先命中夜痕或岑烨，导致：

1. 正常剧情无法达成 F7。
2. 正片 F2 → F7 → F10 的多周目路径无法验收。
3. 当前分支不能合并。

不要删除、跳过或放宽这个失败测试。需要作者先明确：

- 多人同时被选择时采用什么路线优先级或选择规则。
- 如何保证 F7 与后续 F10 仍能通过正常剧情达成。
