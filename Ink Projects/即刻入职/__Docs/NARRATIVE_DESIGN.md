# 《即刻入职》叙事核心与路线设计备忘

- 更新日期：2026-11-19
- 来源：主创（瑞洛凩）创作访谈与设定对齐

---

## 1. 时代背景与故事真相

- **时间点与黑川物流的规模**：
  故事发生时，**黑川物流还不是“黑川集团”**（正文中应统一称“黑川物流”，避免在此时期误用“黑川集团”）。正是因为后来 **No.8（洛书）** 正式加入并执掌市场部，黑川物流才在他的开拓与运营下一路壮大为集团。
- **开局即被捕的意识空间**：
  洛书原为竞争对手物流公司市场部“虎组”组长，是陪旧公司从小做大的元老级人物，却始终未得到应有的回报与重视。故事中洛书的**第一次醒来**，其实就已经是被 **No.AZ** 绑走改造之后、发生在**意识空间**里的事了。
- **循环的真正目的**：
  洛书在意识空间里不断醒来、不断在各条路线中遭遇 AZ，本质上是为了**解决洛书所有的遗憾，打破他的伪装与面具，帮助他成为更好、更真实的自己**，最终在纯白空间中与自己的**胶兽人格**达成和解，从而在现实中作为完整的 **No.8** 醒来，心甘情愿地向黑川物流效忠。

## 2. 洛书的人物内核（主创投射）

- **闷骚与面具**：
  洛书是一个典型的**闷骚**，也是一个**几乎时刻戴着面具**的人。他习惯把真实的欲望、细腻敏感的内心和努力全部藏在云淡风轻的面具背后，不愿在现实中引人注目。
- **原生家庭与身体边界（为什么讨厌被人碰）**：
  - **被迫的跆拳道**：小时候被父亲一厢情愿地逼着去练跆拳道，自己毫无选择权。父亲是个粗暴迟钝的“死直男”，根本不懂内心细腻的人在想什么，洛书能熬过来全凭自己极强的精神抗压能力。
  - **懂装不懂的说教与抢功**：那个“老登”总爱谈论肌肉，却根本不懂科学训练，只会按想当然的方式说三道四；甚至直到今天，老登还自以为是地认为洛书身体好全靠当年逼他练跆拳道。
  - **私密的自留地**：洛书非常抗拒“着了那老登的道”。随着年龄增长，他愈发厌恶父亲乃至任何亲戚看他的身体，**更不愿意让父母或亲戚触碰、谈论他的身体**。他身上的肌肉是自己私下通过**科学、正确的训练**练出来的——他宁可在网上和自己的兽人控（furry）同好朋友们秀自己私下科学练出的肌肉，也绝不愿在现实亲戚或外人面前显露。
  - **藏起来的生存策略**：练了跆拳道后他依然“不敢打架”、显得温和甚至软弱，并非因为打不过，而是他心思细腻、想得太多太远（打了之后呢？无穷的祸患、牵扯赔偿、没完没了的麻烦与挑战）。因此他选择了**“把自己藏起来，让自己不引人注目”**的生存之道。

### 2.1 No.AZ（林幻阳）的人物基调

- **披着白虎皮的黑胶母体、纯纯的数值怪**：
  作为第一代司令级黑胶母体，拥有复数脑机算力、生物拟态、分泌诱捕素、强化肌肉纤维、胶液材料编织等绝对碾压的能力。任何物理层面的反抗在他面前都毫无意义，因此他从不需要靠发怒、恐吓或狰狞来彰显力量，举手投足永远散漫、随和、慢条斯理。
- **无意为之的“神父式引导者”**：
  结合林幻阳原本向往“教育”的前史与天生蛊惑人心的特质，加上母体对子代/藏品的包容与纵容，AZ 在与洛书接触时就像一位温和耐心的神父或导师。但他**并不是刻意摆出神父的姿态去攻心**——他只是出于母体与生俱来的本能和上位者的理所当然，觉得“你绷得这么紧、明明有渴望却不敢承认，那我替你把壳剥开、成全你就好”。这种“毫无恶意却毫无边界感的温和看穿”，反而最能击穿洛书这种闷骚的防线。

## 3. 世界观层级与全路线共通彩蛋

- **藏品 / 胶兽人格 vs. 执行体（兵奴）**：
  - 在黑川物流世界观中，**执行体（兵奴）**是没有自我意识、比较下贱的底层存在。
  - 健身房路线里那些穿着黑色无缝训练服的大只佬会员**都不是执行体**，而是更高级的个体。
- **全路线共通彩蛋——“惊鸿一瞥的另一个自己”**：
  - 在每一条线路里，都可以安排洛书**惊鸿一瞥看到一个“很像自己的人”**。
  - 那个身影**不是执行体，而是洛书自己的“胶兽人格”**（即身体胶化后诞生、卸下面具完成进化后的完美形态）。
  - 洛书不会与他发生直接互动，也不会认出那就是“自己”，但会在擦肩而过或远眺时，**自然而然地羡慕“那个自己”**（羡慕他拥有自己渴望的强悍、自在与毫无顾忌的真实）。

## 4. 普通路线的转折与 Game Over 机制

虽然每条路线都在尝试帮洛书打破伪装、成为更真实的自己，但在前 9 条普通路线的后半程，洛书每次都会在面具即将被揭开时**“突然意识过来”**，并因无法坦然面对而触发以下三种极端防御/崩溃反应之一：

1. **直接摆烂**：一下子放弃所有对抗，自我意识溃散；
2. **精神过载**：被强行揭开伪装（如被薅下面具、读取记忆）时羞愧或震惊到极点，一下子无法接受，导致精神过载崩溃；
3. **过猛抵抗**：拼命抗拒导致把自我意识永远封闭在壳里，无法自拔。

**结果**：一旦自我意识因摆烂、过载或封闭而离线，黑胶就无法与他的自我达成和解，只能退而求其次，将这具失去自我的躯壳覆写、洗脑成没有自我意识、比较下贱的**执行体**（触发各路线的 `Game Over`）。直到所有路线走完，在最后的纯白空间（`Ending__Final_Reconciliation`）中，他才真正直面那个早就知道真相的自己，与胶兽人格畅聊并合二为一。

## 5. 《健身房》路线（`Work__Gym`）定稿设计要点

1. **器械区的胶兽人格彩蛋（`Converge`）**：
   路过公共器械区深蹲架时，看到那个身形轮廓与自己有几分相似、却壮硕了整整一圈的黑衣大只佬（洛书的胶兽人格）。不发生互动、不认出对方，但内心自然流露出对那副强悍躯体与坦然姿态的羡慕。
2. **私教房前半段的铺垫（破冰与科学训练的肯定）**：
   - 面对 AZ“想练成什么样”的提问，内心想变壮，嘴上却戴着面具说“保持健康”。
   - **不明说催眠，不刻意写楼梯接触法**：重点写 AZ 的指导极其科学、专业，一眼看出洛书的底子是“自己私下科学训练、一点点琢磨出来的”，给予他真正的肯定（**被人肯定，而非雄竞**），让洛书在被理解的愉悦中逐渐卸下防备。
3. **转折与衔接（方案 A：力竭仰躺 + 掂大臂触发 PTSD + 黑胶卧推凳锁死）**：
   - 在 AZ 专业的引导下，最后一组卧推真正推到肌肉力竭，大汗淋漓地仰躺在温润如体温的黑色卧推凳上喘息。
   - AZ 的手滑到大臂上“捏了捏、掂了掂”，瞬间与记忆里死直男老登和亲戚在饭桌上碰他身体、对肌肉评头论足、把功劳强按在跆拳道上的厌恶感重合，令洛书猛然惊醒。
   - 洛书本能地想抽回手/起身喝水，却发现刚才练到脱力的双臂与后背已被吸收了汗水的**黑色卧推凳面（活体黑胶）**牢牢吸附锁死；而在数值怪 AZ 面前，物理挣扎毫无意义。
4. **结尾高潮（神父式无意引导 + 强行读取两层记忆 / 当面薅面具 → 羞愧到崩溃沦为执行体）**：
   - AZ 并无恶意，只是像听告解的神父一样好奇“为什么一碰你就又缩回壳里”，顺势通过黑胶连接强行读取洛书的记忆。
   - **两层记忆被当面扒开**：
     1. **第一层（极力掩饰的伤疤与拧巴）**：小时候被死直男老登逼练跆拳道、不敢打架不是打不过而是想得太远怕惹无穷祸患、只能把自己藏起来，以及对老登抢功劳和亲戚碰身体的厌恶；
     2. **第二层（打死也不想被现实外人看见的闷骚底牌）**：关起门来独自对着资料科学练肌肉、对着镜子暗爽，甚至在网上和兽人控（furry）同好朋友秀身材时的坦率与得意，以及刚刚羡慕那个黑衣大只佬、偷瞄 AZ 胸肌紧身衣时的私密悸动。
   - **羞愧崩溃**：苦心维持二十多年的面具在 AZ 温和包容的注视下被一把薅得干干净净，灭顶的羞耻感直接让洛书精神过载/自我封闭崩溃。由于自我意识断线，黑胶只能退而求其次写入底层指令，将他改造成失去自我的健身房执行体（`Ending__Work__Gym`），留下 AZ 一声惋惜的叹息。

## 6. 九条路线“剥下面具”总纲规划（草案，待逐条细化与改写）

> **设计原则**：九条路线从外层社会铠甲一路剥向私域防线与最后一道理智，最终自然收束进退无可退的纯白空间（`Ending__Final_Reconciliation`）。  
> **改写说明**：除已定稿大纲的《健身房》外，其余八条均为待细化的主题方向参考；主创明确表示**部分老旧旧稿需要大改（例如《出差》）**，后续逐条立项大纲时以主创最新构思为准，不被旧稿束缚。
