# 《测测你是什么狗》开发与维护文档

- 归属企划：黑川物流（Kurokawa Logistics）沙雕测试支线
- 主入口文件：[`测测你是什么狗.ink`](../测测你是什么狗.ink)
- 题库规模：9 大主题题组 × 每组 3 题 = **27 道沙雕选择题**（共 108 个作答选项，每题底部均附带**返回上一题／返回标题页**防手滑功能）
- 结果数量：**12 种五字称号犬科鉴定结果**

## 3. 对称计分与无损返回上一题机制

### 对称正交区组计分
- **题组 01–03（行为本能轴）**、**题组 04–06（职场表现轴）**、**题组 07–09（深层灵魂轴）** 采用三次相互正交的四组划分并轮转主次权重（`+3 / +2 / +1`）。
- 在全部 $3^9 = 19,683$ 种随机 9 题组合中，**每一种狗的理论最高分恒为 18 分**（27 题模式下恒为 **54 分**），绝无数学偏置。

### 防手滑「返回上一题」设计
- 第 1 题底部显示 `[⬅️ 返回标题页]`，第 2 题起每道题底部均显示 `[⬅️ 返回上一题]`。
- 速测模式在开局即固定本局抽出的 9 道题序号（`PICK_P01`–`PICK_P09`），撤回重选时回到**刚才手滑的那道原题**，不会重新随机换题。
- 每一步的作答向量与上一主倾向均编码保存在 `HIST_01`–`HIST_27` 中，支持从最后一题一路连续退回第 1 题并精确回滚全部分数，不产生任何残留分差或隧道调用栈堆积。
