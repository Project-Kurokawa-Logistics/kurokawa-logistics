## 3. 对称计分原理（Symmetric Block Design）

为了同时支持「随机 9 题速测」与「完整 27 题深测」且不产生任何冷门不可达结果，9 个题组采用正交区组设计：

- **题组 01–03（行为本能轴）**：按「顺从狂热 / 乖巧牛马 / 烈性高能 / 腹黑高智」四组轮转主次权重（`+3 / +2 / +1`）。
- **题组 04–06（职场表现轴）**：正交重组为「感官直球 / 老道稳重 / 硬核铁血 / 脱线吃瓜」四组轮转主次权重。
- **题组 07–09（深层灵魂轴）**：二次正交重组，使任意两种狗在全部 9 个题组中最多只共处同一选项 1 次。

由此保证：
1. 在全部 $3^9 = 19,683$ 种随机 9 题组合中，**每一种狗的理论最高分恒为 18 分**（27 题模式下恒为 **54 分**），绝无数学偏置。
2. 即使受试者混搭作答，系统也会平滑结算主犬种，并在结果分割线下方附注检出的第二高分「隐性犬种基因」。

## 4. 快速预览卡片与自动化测试

### 在 Inky 中快速预览全部 12 张结果卡
打开 [`测测你是什么狗.ink`](../测测你是什么狗.ink) 后，在标题菜单连续点击 **5 次** `————————` 分隔线，即可激活「人事部后台权限」，直接点击检视全部 12 张卡片与图片排版。

### 运行编译与回归测试
```bash
cd "Ink Projects/测测你是什么狗/__Tests"
npm install
npm test
```
测试套件将自动验证 15 个 `INCLUDE` 模块 0 错误 0 警告编译，并逐一模拟 12 种犬科人格在全量与多随机种子速测模式下的精准命中。
